# Model assumptions and boundaries

The project calculates a simplified material balance and unlevered cash flow. Recovery yield is assumed to represent saleable product output after process losses. Gate fees are applied to incoming feedstock. Variable operating cost is applied per input tonne; fixed costs are annual. Depreciation is straight-line for the illustrative tax calculation; financing costs, working capital, inflation, escalation and terminal value are excluded unless added explicitly.

Replace all assumptions with dated and sourced project inputs. A commercial feasibility model should separate polymers and contamination, account for process-specific yield and quality, reject/residue disposal, utilities, labour, logistics, permitting, environmental compliance, equipment replacement, downtime and working capital.
